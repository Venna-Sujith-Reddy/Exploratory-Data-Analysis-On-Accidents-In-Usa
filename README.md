# Exploratory Data Analysis — US Traffic Accidents

Temporal pattern analysis on a large US traffic-accident corpus (**2016–2021**).

## Questions explored
- At what **hour of day** do accidents peak?
- Which **day of week** is riskiest?
- How do rates vary by **month**?
- Are accidents trending up or down over time?

## Stack
`Python` · `pandas` · visualization · Jupyter (`EDA.ipynb`)

## Run
```bash
jupyter notebook EDA.ipynb
```
